    Cole o link de cada foto ou vídeo. Abra os tutoriais abaixo se precisar.
    📷 Como obter o link de uma foto (ImgBB — grátis)
    1. Abra https://imgbb.com no navegador (funciona no celular).
    2. Toque em Start uploading / enviar.
    3. Escolha a foto da galeria.
    4. Após o envio, em Direct links / Links diretos, toque em Copy.
    5. Cole o link no campo acima (uma foto por linha).
    ✅ Link bom termina com .jpg / .png / .webp — ex: https://i.ibb.co/abc/moto.jpg

    Alternativas: postimages.org ou imgur.com (upload → copiar “direct link”).

    📁 Google Drive — passo a passo (foto ou vídeo)
    1. Envie o arquivo para o Google Drive.
    2. Toque no arquivo → Compartilhar.
    3. Acesso geral: Qualquer pessoa com o link → Leitor.
    4. Toque em Copiar link. Fica assim:
      https://drive.google.com/file/d/ID_DO_ARQUIVO/view?usp=sharing
    5. Cole esse link no anúncio — o sistema converte sozinho.

    Se a foto não aparecer, converta manualmente:

    1. Copie só o ID (entre /d/ e /view).
    2. Use este formato:
      https://drive.google.com/uc?export=view&id=ID_DO_ARQUIVO
    Ex.: ID 1aBcD2eFg → https://drive.google.com/uc?export=view&id=1aBcD2eFg

    🎥 Vídeo no Drive: cole o link normal de compartilhamento (/file/d/.../view).

    ▶️ Vídeo do YouTube
    1. Abra o vídeo no YouTube → Compartilhar → Copiar link.
    2. Cole no campo (youtube.com/watch?v=... ou youtu.be/...).
